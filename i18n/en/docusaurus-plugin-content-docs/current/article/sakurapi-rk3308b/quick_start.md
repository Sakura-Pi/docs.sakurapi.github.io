# Quick Start

## Firmware
The Sakura Pi RK3308B does not come with any pre-installed operating system, so you will need to manually download and flash one yourself.

Currently, the device supports the following operating systems:

| Status | Distrobution | Version | Link |
|:--|:--|:--|:--|
| 🟢 Active  | Armbian - _**Debian 13 Trixie**_| Latest | [🔗 Download](https://dl.armbian.com/sakurapi-rk3308b/Trixie_current_minimal) |
| 🟡 Repo  | OpenWRT | 24.10 | [🔗 GitHub](https://github.com/Sakura-Pi/openwrt/tree/openwrt-24.10) |
| 🟡 Repo  | Buildroot | 2025.08-rc2 | [🔗 GitHub](https://github.com/Sakura-Pi/buildroot/tree/sakurapi-rk3308b) |
